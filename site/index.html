second-windprivate preview

A Claude Code skill that hands work to the other AI subscriptions you already pay for, through their own clients, and logs every call.

Independence

A reviewer that watched you build it is not a reviewer.

A second Claude account, or Codex, arrives with none of your context. That is what you want when the work needs challenging rather than confirming.

Headroom

Every subscription has its own usage window.

When your main account gets close to its limit, the heavy work moves to another account you already pay for and you carry on.

Three levels, chosen at setup

Reviewer

Read-only second opinions. Nothing in your session changes and no hooks are installed.

Worker

Full read and write handover when you ask for it. The worker does the job in the current directory.

Relief

Worker, plus automatic handover when the main account nears its limit. It waits for a task boundary and tells you.

How it works

  1. 1Write the brief for the worker in plain language.
  2. 2One runner sends it to the chosen client.
  3. 3The prompt, the reply and the outcome land in the ledger.
  4. 4Any handover announces which account did the work.

What it will not do

  • No relay. Official clients only, one sign-in per account, each subscription billed to itself.
  • No token sharing. Nothing here reads, copies or moves a credential.
  • No silent rotation. Handover happens at a task boundary and says so in the session.

Install

git clone https://github.com/bilalhassam-cr/second-wind second-wind
cd second-wind && ./install.sh

Restart Claude Code, then say set up second-wind. Needs macOS, Claude Code 2.1.251 or newer on your PATH, jq, Python 3.9 or newer, and one other paid subscription. Read your own plan's terms before you install it.
